# 워치 데이터와 마음섬 · 0.6.0

워치에서 폰에 동기화된 기록을 읽어 마음섬의 활동 추천과 움직임 미션에 연결합니다. 연결·페어링·펌웨어·원본 데이터 쓰기 코드는 변경하지 않습니다.

## 사용자 흐름

1. 건강 화면에서 워치 데이터를 동기화하고 마음섬을 엽니다.
2. 첫 화면에서 오늘 걸음, 최근 밤 수면, 최근 기록 심박과 활동 제안의 이유를 확인합니다.
3. 산책·몸 풀기·쉬어가기 중 선택합니다. 직접 남긴 쉼 느낌과 마음 날씨도 반영합니다.
4. 퀘스트에서 **지금 걸음에서 시작하기**를 누르면 현재 걸음을 기준으로 추가 300걸음을 모읍니다.
5. 산책 후 건강 화면에서 동기화하고 돌아오면 진행도가 갱신됩니다. **씨앗 4개 받기**로 보상을 받습니다. 자동 지급은 아닙니다.

마음섬을 보고 있는 동안 20초마다 폰의 저장된 기록을 다시 읽습니다. **기록 새로 읽기**는 BLE 동기화 명령이 아닙니다. 건강 화면에서 진행한 동기화 결과만 읽습니다.

## 추천 규칙

| 조건 | 제안 |
| --- | --- |
| 직접 남긴 쉼이 ‘더 쉬고 싶어요’ | 몸 풀기와 회복 우선 |
| 최근 밤 수면 추정이 8시간 미만 | 가벼운 몸 풀기, 주관적 컨디션 확인 |
| 걸음 누락·오래된 기록 | 동기화 안내와 직접 활동 선택 |
| 직접 남긴 마음이 흐림·비·바람 | 선택 가능한 짧은 산책·몸 풀기 |
| 오늘 걸음이 이전 7일 중 기록 있는 날의 중앙값 이상, 최소 3일 | 더 채울 의무 없는 쉬어가기 |
| 그 외 최근 걸음이 있음 | 추가 300걸음의 작은 산책 |

300걸음은 **게임 목표**이며 권장 운동량이나 의료 기준이 아닙니다. 이전 날과 비교할 때는 완결된 하루의 중앙값임을 화면에 표시하고, 오늘 도중의 낮은 걸음을 ‘부족’으로 진단하지 않습니다. 심박은 최근 기록을 보여주되 운동 강도·감정·보상을 결정하지 않습니다. 24시간 이상 지난 심박은 표시하지 않습니다. 누락된 측정은 0으로 바꾸지 않습니다.

수면의 8시간 분기에는 [CDC의 청소년 수면 안내](https://www.cdc.gov/healthy-schools/sleep/index.html)를 참고했습니다. 개인별 운동 처방이나 수면 진단이 아닙니다. [CDC 신체활동 지침](https://www.cdc.gov/physical-activity-basics/guidelines/children.html)의 하루 활동 권고와 작은 게임 목표는 다릅니다.

## 데이터 경로와 보존

- `WatchSnapshot.java`는 기존 `MyDb` Room 인스턴스의 공개 DAO를 읽기 전용으로 호출합니다. 독립 Java/DEX의 SDK 종속성을 피하기 위해 리플렉션을 사용합니다.
- 걸음은 건강 홈과 동일한 `ActivityDao.getActivity(start,end)`의 최신 일 누적 기록입니다. 개별 활동을 합산하지 않아 중복 집계를 피합니다.
- 수면은 건강 홈의 날짜 범위와 `SleepDataParse` 또는 `SleepAllDayDataParse`의 `getTotal()`을 사용합니다. 새 수면 분석 알고리즘을 만들지 않습니다.
- 심박은 `HeartRateDao.getLastHeartRate()`이며 측정 당시 운동 여부를 알 수 없어 처방에 쓰지 않습니다.
- 브리지는 필요한 집계 값만 로컬 WebView에 전달합니다. 주소·계정·메모·전체 원시 센서 배열을 전달하거나 새 서버에 업로드하지 않습니다. 기존 건강 앱의 서버 동기화는 별도입니다.
- 마음섬 저장 형식 1을 유지하며 선택 항목 `watchWalk`만 추가합니다. 기존 기분·씨앗·꾸미기·쉼 기록을 유지합니다.
- 300걸음과 직접 완료하는 움직임 퀘스트는 동일한 일일 보상을 공유합니다. 양쪽을 눌러도 중복 지급되지 않습니다. 걷기 어려울 때 몸 풀기로 같은 보상을 받을 수 있습니다.
- 시작/수령에는 오늘 날짜, 최근 30분 이내 걸음 기록, 최근 1분 이내 읽은 스냅샷이 필요합니다. 미래 시각과 누락값을 거절하며 수령 시 시작 이후 측정값인지 확인합니다. 누적 걸음이 줄면 다시 시작하도록 안내합니다.

## 검증

```powershell
node tests/mind-island-model.test.cjs
node tests/watch-coach.test.cjs
```

기존 규칙, 누락·오래된·미래 측정, 추천 우선순위, 목표 전 수령 거절, 누적값 감소, 시작 이전 기록 거절, 저장 복원, 직접 완료와 워치 보상의 중복 방지를 검사합니다. 휴대폰의 실제 데이터 읽기와 화면 검증 결과는 별도 검증 기록에 남깁니다. 실제 산책 300걸음의 전체 완료는 사용자 확인이 필요합니다.

실물 Galaxy S25에 0.6.0 업데이트 설치 후 기존 건강 저장소 읽기와 실제 심박 표시를 확인했습니다. 확인 당시 오늘 걸음·수면 기록은 없어 누락 안내를 검증했습니다. 실제 산책 후 300걸음 달성과 수면 기록 표시까지 검증한 것은 아닙니다. [검증 기록](../analysis/watch-coach-0.6.0-verification.json)을 참고하세요.
