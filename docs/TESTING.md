# Diz-SW01 설치·연결 테스트

## 현재 알려진 설치 차단

2026-11-02 사용자 기기에서 기준 APK 설치 중 ‘악성 앱으로 의심’ 경고와 해제할 수 없는 차단이 보고됐습니다. 다운로드 링크 오류가 아닌 설치 단계의 보안 경고입니다. 원인 확인 전 기준 APK의 설치를 보류합니다. [조사 기록과 공식 검토 경로](SECURITY_BLOCK.md)를 확인하세요. 아래 절차는 이 문제가 검토된 이후 사용할 테스트 계획이며 설치 성공을 뜻하지 않습니다.

## 현재 확인된 것

사용자가 Diz-SW01이 기존 앱에 연결됐다고 확인했습니다. 이번 테스트 APK는 휴대전화에 설치하거나 워치와 연결해 검증하지 않았습니다. 정적 검증만 통과했습니다.

- APK Signature Scheme v2·v3 검증 통과.
- ZIP 정렬 검증 통과.
- 원본 리소스 ID 30,432개 보존.
- DEX 페이로드와 ARM64 라이브러리 50개 보존.

[단일 APK 검증 자료](../analysis/standalone_verification.json)에 SHA-256과 대상 SDK, 파일 구성 정보가 있습니다.

## 설치 전

APK는 ARM64 Android 8.0(API 26) 이상 대상이며, 모든 CPU를 지원하는 범용 APK가 아닙니다. 원본과 같은 앱 ID에 다른 서명을 사용하므로 기존 앱과 동시에 설치하거나 덮어 업데이트할 수 있다고 가정하면 안 됩니다.

기존 앱을 삭제하면 앱 내부 기록·설정이 사라질 수 있습니다. 백업·계정 동기화 상태를 먼저 확인하고 가능하면 별도 테스트용 휴대폰을 사용하세요. 워치 초기화나 펌웨어 업데이트는 이번 기본 연결 시험에 필요하지 않습니다.

## 설치

Release에서 APK를 받아 ARM64 휴대폰에서 엽니다. 해당 파일 앱이나 브라우저에 필요한 '이 출처의 앱 설치' 권한을 허용합니다. 설치 실패 시 Android 버전·CPU·기존 앱 존재 여부와 표시된 오류를 기록하세요. Play Protect 등의 결과를 자동으로 무시하는 절차는 포함하지 않습니다.

## 순서별 테스트 표

| 단계 | 확인할 내용 | 남길 증거 |
| --- | --- | --- |
| 1 | 앱 실행, 첫 화면·한국어 표시 | Android 버전, 휴대폰 모델, 스크린샷, 종료 여부 |
| 2 | Bluetooth·알림 등 필요한 권한 요청 | 허용/거부 상태와 안내 화면 |
| 3 | Diz-SW01 스캔 결과 | 화면에 표시된 기기 이름과 검색 시간 |
| 4 | 연결·서비스 탐색·바인딩 | 연결 상태, 실패 코드, 필요 시 비식별화한 logcat |
| 5 | 시간·배터리·기기 정보 읽기 | 워치와 앱의 값 비교 |
| 6 | 걸음·심박·수면 읽기 | 최신 기록과 시간대·단위 비교 |

처음부터 모든 기능을 켜거나 펌웨어를 갱신하지 마세요. 한 단계가 실패하면 다음 UI·프로토콜 변경을 섞기 전에 원인부터 기록합니다. 로그를 공유할 때 계정 토큰·개인 건강 기록·연락처·기기 식별자는 가립니다.

## 연결 실패 원인 후보

- 앱 서명·패키지명을 확인하는 SDK 또는 서버 인증.
- 제조사 서버에 저장되는 기기 바인딩·사용자 상태.
- Bluetooth·알림·위치·포그라운드 서비스 권한 상태.
- 이전 휴대폰 또는 원 앱과의 활성 연결.
- 모델별 프로토콜 분기와 기능 플래그.

이 항목들은 검증 후보이며 현재 이 앱에서 실제 원인이라고 확인한 것은 아닙니다. 포함된 여러 SDK만 보고 Diz-SW01의 칩셋이나 UUID를 단정하지 않습니다.
