# 마음섬 워치 연동 확장 버전

## 개발 기준

- 개발 브랜치: `codex/mind-island-watch-integration`
- 기준 버전은 브랜치 생성 시의 main. main 및 기존 배포 APK를 변경하지 않는다.
- 별도 배포 APK를 제공한다. 기존 설치본과 동시 설치를 지원하려면 별도 application_id, provider authority, 권한/서비스 연결을 검토하고 기기 연결 충돌도 검증해야 한다. 아직 식별자는 변경하지 않았다.
- 음성 입력과 알림은 별도 시험 앱에서 검증됐으며 본 앱 통합 완료를 의미하지 않는다.

## 구현 순서와 확인 기준

1. **마음섬 음성 입력**: 기존 마음 날씨 선택 화면에 ‘워치로 말하기’를 추가한다. 사용자 시작 → 전화용 연결 확인 → SCO 입력 → 한국어 구간 인식 → 문구와 마음 날씨 후보 표시 → 사용자 확인 → 기존 마음섬 저장 흐름으로 전달한다. 인식 실패 시 직접 선택을 제공하고 자동 저장하지 않는다. 시작/중단/화면 이탈 시 오디오와 인식기 자원을 정리한다. 실제 워치로 여러 마음 날씨를 시험하고 재연결 및 저장 유지 여부를 확인한다.
2. **마음섬 쉼 알림**: 마음섬에서 시험 알림 한 건을 보내고 실제 표시·진동을 확인한다. 기존 앱의 알림 전달 코드가 자기 패키지를 제외할 수 있으므로, 시험 앱의 POST_NOTIFICATIONS 코드만 복사해 완료로 판단하지 않는다. 본 앱의 워치 전송 경로를 확인한다. 자동 건강 조건 알림은 이 단계에 포함하지 않는다.
3. **마음섬 워치페이스**: 승인된 ‘섬 위 · 시간 아래’ 배치를 사용한다. 사용자의 현재 섬을 배경 이미지로 내보내고 기존 워치페이스 전송 기능과 연결한다. 이미지에 시간을 고정하지 않고 워치의 실제 시계를 유지한다. 워치 화면 표시를 실물 확인한다.
4. **확장 APK 검증·배포**: 별도 버전명과 설치 정책을 확정하고 빌드한다. 설치·연결·기존 기능·새 기능을 S25/Diz-SW01에서 검증한 뒤 새 브랜치에 소스와 재현 가능한 빌드 절차를 푸시한다. 다운로드 가능한 APK와 설치 안내를 별도로 제공한다. main 병합이나 기존 릴리스 교체는 하지 않는다.

## 첫 화면 흐름 초안

마음섬 → 오늘의 마음 → 워치로 말하기 → ‘오늘 마음 흐림’ → 인식 문구 확인 → 흐림 선택/수정 → 저장

마음섬 → 잠깐 쉬어가기 → 시험 알림 보내기 → 워치 표시·진동 확인

## 현재 상태

본 앱의 음성 Activity, 마음 날씨 파서, Activity 실행·결과 수신 연결, 마음섬 진입 버튼과 날씨 적용을 구현했다. Java/DEX 컴파일과 기존 모델 검사 및 음성 UI 검사를 통과했다. 별도 설치용 `profiles/diz-sw01-watch-integration.json`을 추가했다. 전체 APK 빌드와 실물 통합 검증은 진행 중이다. 기존 main은 변경하지 않았다. 쉼 알림과 워치페이스의 본 앱 통합은 다음 단계다.
