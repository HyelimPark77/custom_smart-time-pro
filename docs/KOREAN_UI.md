# 한국어 UI 시안 0.2.0

기존 APK의 리소스·레이아웃을 수정했다. Smali의 통신·계정·건강 데이터 로직은 변경하지 않았다.

- 흰색과 회녹색 바탕, 청록색 포인트, 테두리 카드로 색상을 정리했다.
- 건강 홈의 걸음 수 카드에서 큰 숫자와 거리·소모 열량을 나눠 표시한다. 기존 숫자 뷰와 데이터 바인딩 ID·타입을 유지했다.
- 심박수·수면·스트레스·체중 등의 빈 상태 카드에서 입체 그림을 선형 벡터 아이콘으로 교체했다.
- 운동 기록, 워치 연결 카드, 하단 메뉴, 초기 안내 화면의 디자인을 정리했다.
- 기존 한국어 리소스 약 2,600개를 기본 문구로 재사용하고, 주요 메뉴와 빈 상태 문구를 다듬었다. 제조사 서버·웹페이지·일부 SDK의 문구까지 모두 한국어화한 것은 아니다.

프로필: `profiles/diz-sw01-korean-ui.json`

- 표시 이름: 디즈 워치
- 앱 ID: `com.diz.sw01.custom.ui`
- 버전: 0.2.0 / 2
- 결과 APK: `Diz_SW01_Korean_UI_0.2.0_ARM64_TEST.apk`

새 로컬 서명 키를 사용하므로 기존 Release 앱과 비교할 수 있도록 별도 앱 ID를 사용했다. 기존 테스트 앱이나 앱 데이터를 제거하지 않는다. 이 APK의 첫 실행 안내·동의는 별도로 표시된다.

## 재빌드

Java와 Python이 있는 PowerShell에서:

```powershell
# 선택: Windows의 깊은 경로로 빌드가 실패하면 복원 작업 공간을 짧은 경로에 두고 지정
$env:SMART_TIME_WORKSPACE = 'C:\build\diz-ui'
.\scripts\Build.ps1 -IdentityProfile .\profiles\diz-sw01-korean-ui.json
```

이 PC에서는 복원된 빌드 작업 공간을 `C:\Users\hyoh7\Documents\Codex\work\diz-ui`로 이동해 사용했다. `workspace/SMART_TIME_PRO_customization` 기본 경로를 사용하는 환경에서는 환경 변수 지정이 필요 없다. 경로 변수는 현재 세션에서만 설정한다. 서명 키는 빌드 작업 공간의 `test-only.jks`에 있으며 Git이나 패치 ZIP에 포함하지 않는다.

## 검증

- Apktool 리소스 컴파일과 APK 재조립 완료.
- APK 서명 v2·v3 및 ZIP 정렬 검사 통과.
- 수정 레이아웃의 기존 view ID·클래스 타입 보존 검사 통과.
- API 31 Google APIs x86_64/ARM64 변환 에뮬레이터에 설치 성공.
- 한국어 최초 안내와 개인정보 입력 화면, 건강 홈 및 기기 탭 전환을 확인했다. 실화면 점검에서 발견한 운동 카드 배경 충돌·잔여 그라데이션·레거시 아이콘을 수정했다.
- 원래 테스트 APK와 DEX 21개 및 네이티브 라이브러리 50개가 바이트 단위로 일치하는 것을 확인했다.
- 실제 워치 검색·연결·동기화와 서버 로그인은 이 UI 작업에서 검증하지 않았다. 기존 보안 차단 조사 상태는 달라지지 않는다.

## 오프라인 UI 미리보기

최종 APK를 에뮬레이터에 업데이트 설치한 뒤 건강 홈과 기기 탭을 다시 시각 점검했다. 확인한 AndroidRuntime 로그에 FATAL EXCEPTION은 없었다.

온라인에서는 원 제조사 서버의 강제 업데이트 안내가 나타나 화면을 가렸다. 이 동작은 UI 리소스 수정만으로 해결하지 않았다. 최종 화면 확인은 에뮬레이터의 Wi-Fi와 모바일 데이터를 꺼서 수행했으며, 현재 가상 기기는 오프라인 상태로 두었다. Bluetooth 상태를 변경한 것은 아니다. 현재 버전은 오프라인 UI 미리보기이며 온라인 사용 준비가 완료된 버전은 아니다.

가상 기기 인터넷을 다시 켜려면 SDK의 adb로 다음 명령을 실행할 수 있다. 켜면 제조사 업데이트 안내가 다시 나타날 수 있다.

```powershell
adb -s emulator-5580 shell svc wifi enable
adb -s emulator-5580 shell svc data enable
```
