테스트 APK 안내

SMART_TIME_PRO_2.1.3.4_ARM64_TEST.apk는 원본 앱의 화면·동작을 유지한 기준 테스트 빌드입니다.
원본 XAPK의 기본 APK, ARM64 라이브러리, xxhdpi 분할 리소스를 한 APK로 합쳤습니다.
ARM64 Android 8.0(API 26) 이상 기기를 대상으로 합니다.
다른 CPU용 라이브러리를 새로 만든 범용 APK는 아닙니다.

설치 전
- 아직 실제 휴대폰 실행·Diz-SW01 연결은 검증하지 않았습니다.
- 원본 앱과 같은 패키지명(com.sma.smartv3.pro)이지만 서명은 별도 테스트 키입니다.
- 기존 앱 위에 업데이트 설치하려 하면 서명 불일치로 설치가 실패할 수 있습니다.
- 기존 앱을 지우면 앱 내부 데이터가 사라질 수 있습니다. 먼저 백업·데이터 이전을 준비하세요.
- 가능하면 기존 앱과 워치의 현재 상태를 유지한 채 별도 테스트용 휴대폰에서 확인하세요.

설치와 확인
1. APK를 ARM64 휴대폰으로 복사하고 파일을 열어 설치합니다.
2. 사용하는 브라우저/파일 앱에 필요한 '이 출처의 앱 설치' 허용을 선택합니다.
3. 실행 후 블루투스와 필요한 권한을 허용합니다.
4. Diz-SW01 검색, 연결, 시간 동기화와 건강 데이터 읽기를 확인합니다.
5. 화면 꺼짐·앱 재시작·휴대폰 재부팅 후 재연결을 확인합니다.
6. 앱 알림과 워치페이스는 기본 연결을 확인한 뒤 별도로 테스트합니다.
이번 테스트에 펌웨어 업데이트나 복구 동작은 필요하지 않습니다.

서명 키
test-only.jks는 로컬 분석 폴더에 보관한 개발용 키이며 공개 저장소·번들에는 포함하지 않습니다.
새 환경에서 Build-TestApk.ps1를 실행하면 해당 환경의 새 테스트 키가 생성됩니다.
그 키로 서명한 APK는 게시된 기준 APK 위에 업데이트되지 않을 수 있습니다.
별칭 androiddebugkey, 키/저장소 암호 android.
공개 배포나 상용 제품 서명에 사용하지 마세요. 배포용 키는 별도로 만들어 관리해야 합니다.

이 APK는 공식 배포본이 아니며 제조사 서버·OAuth·지도 SDK 등이 테스트 서명을
허용하는지는 별도 확인이 필요합니다. 설치 성공과 워치 연동 성공은 구분해서 확인합니다.
