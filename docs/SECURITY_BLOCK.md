# 기준 APK 설치 보안 차단 조사

## 2026-11-02 보고된 증상

사용자가 게시된 기준 APK를 설치하려 했을 때 휴대전화가 ‘악성 앱으로 의심’ 경고를 표시했습니다. 화면은 악성으로 신고됐거나 유사한 앱이어서 피싱에 사용될 수 있으며 해당 제한은 끌 수 없다고 안내합니다. 설치 보안 차단이며, 화면 자체는 GitHub 다운로드 주소 오류나 ZIP 정렬 오류의 증거가 아닙니다.

현재 APK의 설치를 보류합니다. 경고가 실제 악성 동작 탐지인지, 유사도·평판·민감 권한 관련 차단인지 확정하지 않았습니다. 사용자 스크린샷과 개인 기기 정보는 이 공개 저장소에 업로드하지 않았습니다.

## 확인한 APK와 사실

- 파일: `SMART_TIME_PRO_2.1.3.4_ARM64_TEST.apk`
- SHA-256: `647af0c0be5f692bd4c35f40f1488475a55901b57ff123d54bfd9886a9bf8dac`
- 앱 ID: `com.sma.smartv3.pro`
- 원 제작자의 인증서와 다른 로컬 테스트 인증서로 서명했습니다.
- SMS 읽기 `android.permission.READ_SMS`를 선언합니다.
- `com.sma.smartv3.ble.MyNotificationListenerService`가 `android.permission.BIND_NOTIFICATION_LISTENER_SERVICE`를 사용합니다.
- 통화기록·연락처·녹음·다른 앱 위에 표시 관련 권한도 원본에서 보존됐습니다.
- APK 서명 v2·v3, ZIP 정렬, 리소스·DEX·네이티브 보존은 검증했습니다. **이는 악성코드 안전성 평가 또는 기기의 설치 허용을 보장하지 않습니다.**

권한은 `patches/base/AndroidManifest.xml`에서 확인할 수 있습니다. 알림 접근 서비스는 원래 워치 알림 전달을 위한 것으로 보이지만, 서비스의 전체 동작·전송 범위·사용자 동의를 별도로 검토해야 합니다.

## 공식 설명과 이 사례의 구분

[삼성의 공식 설명](https://www.samsung.com/sec/business/insights/news/news-220523_6/)에는 외부에서 설치되는 앱에 대한 보이스피싱 방지 및 악성·출처 불명 앱 차단이 안내돼 있습니다. [Samsung Members 운영 담당자의 유사 경고 답변](https://r1.community.samsung.com/t5/서비스-기타/악성-앱으로-의심/td-p/25249060)도 외부 배포 앱에 대한 차단과 검토 절차를 설명합니다. 후자는 2024년 답변이므로 현재 기기의 최신 절차를 지원 담당자에게 확인해야 합니다.

[Google Play Protect 개발자 안내](https://developers.google.com/android/play-protect/warning-dev-guidance)는 일부 시장에서 인터넷으로 배포된 앱의 SMS 읽기·알림 접근 등 민감 권한이 설치 차단과 관련될 수 있다고 설명합니다. 동시에 사용자 동의 아래 워치로 알림을 전달하는 건강·피트니스 앱은 알림 접근의 정상적 용도 예시로 명시합니다. **권한이 존재한다는 것만으로 이 APK가 악성이라고 단정할 수 없고, 정상적인 용도만으로 안전성을 증명할 수도 없습니다.**

사진만으로 해당 기기의 판정 주체가 삼성인지 Google Play Protect인지 확정하지 않았습니다. 이 사례에서 어떤 권한·코드·서명·평판이 판정에 영향을 미쳤는지도 아직 확인하지 않았습니다. 단순한 오탐이나 ‘테스트 서명이라서 발생한 경고’라고 결론 내리지 않습니다.

## 다음에 필요한 정보

1. 휴대전화 모델, Android 버전, One UI 버전.
2. 경고 직전 설치 화면과 보안 알림에 표시된 판정 서비스 이름.
3. 공식 앱이 현재도 같은 기기에서 정상 설치·사용되는지.
4. 기기 보안 기록이나 제조사 지원 답변에 표시된 판정명. 개인 기록·토큰은 공유하지 않습니다.

사용자가 휴대전화 모델을 **Galaxy S25, SM-S931N**으로 확인했습니다. Android·One UI 버전 및 판정 서비스 이름은 아직 확인하지 못했습니다. 이후 요청에 따라 앱 이름과 앱 ID를 분리한 [커스텀 식별자 빌드](CUSTOM_APP_IDENTITY.md)를 준비했으며, 이 변경으로 보안 판정이 해결됐다고 주장하지 않습니다.

## 해결 작업의 순서

1. 보안 차단 기록과 기기 정보를 통해 판정 주체를 확인합니다.
2. 원본·재조립본의 권한, 인증서, 변경 내역을 비교합니다. 서명 검증 결과를 안전 판정으로 취급하지 않습니다.
3. SMS·알림·연락처 등 실제 사용하는 기능과 사용자 동의, 전송 범위, 타사 SDK를 검토합니다. 기능에 불필요한 권한은 관련 코드·요청 화면까지 함께 제거해야 하며, 매니페스트만 지워 정상 동작한다고 가정하지 않습니다.
4. 삼성 차단이면 Samsung Members 또는 공식 고객지원으로 검토 절차를 확인합니다. [삼성 공식 오류 보내기 안내](https://www.samsungsvc.co.kr/solution/2683703?assess=N)의 Samsung Members 항목을 참고합니다.
5. Play Protect 판정이면 [공식 개발자 안내의 이의 제기 경로](https://developers.google.com/android/play-protect/warning-dev-guidance)를 사용합니다. 타사 앱 소유권을 가장하거나 원 제작자의 인증서를 사용한다고 주장하지 않습니다.
6. 검토 결과와 수정 사항이 확인된 이후 설치·Diz-SW01 연결을 검증합니다. 공식 스토어용으로 배포할 때도 권리·개발자 등록·서명·개인정보 요구사항을 별도로 충족해야 하며 등록만으로 승인을 보장하지 않습니다.

보안 설정 해제, 강제 설치, 패키지명·서명·파일 포맷을 바꿔 탐지를 피하는 방법은 이 문제의 해결 절차에 포함하지 않습니다. 초기 조사 후 사용자의 별도 앱 분리 요청에 따라 이름·앱 ID를 변경한 테스트 APK를 만들었지만 보안 판정 해결책으로 제시하지 않습니다. 제조사·Google에 파일을 자동 제출하지 않았습니다.
