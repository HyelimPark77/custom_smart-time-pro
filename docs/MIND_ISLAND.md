# 마음섬 0.3.0

건강 홈의 **마음섬** 카드를 누르면 열리는 오프라인 게임이다. 기존 한국어 UI 앱(`com.diz.sw01.custom.ui`)과 같은 서명으로 업데이트 설치한다. 기존 워치·계정·건강 기록을 삭제하지 않는다.

## 구현한 기능

- **나의 섬:** SVG로 그린 작은 섬, 무료 배경 3종, 꾸미기 6종, 배치 자리 3개. 모은 꾸미기는 이동하거나 치워도 소유권이 유지된다.
- **마음 날씨:** 날씨 5종, 선택 메모 200자, 최근 일주일 기록. 어떤 날씨든 하루 첫 기록은 같은 씨앗 5개를 받고, 같은 날 수정은 중복 보상이 없다.
- **작은 퀘스트:** 산책 또는 앉아서 몸 풀기, 물 챙기기·안부 묻기·창밖 보기 중 선택하는 작은 용기, 1분 휴식. 각 퀘스트는 본인이 완료를 기록하며 하루 한 번 씨앗 4개를 받는다.
- **쉬어가기:** 60초 호흡 게임. 4초 들이쉬고 4초 내쉬는 시각 안내, 멈춤·이어가기·그만두기, 백그라운드 자동 일시정지. 한 번에 몰아 하지 않고 잠시 멈췄다 이어갈 수 있다. 완료 보상은 하루 한 번 씨앗 3개다.
- **쉼 기록:** 주관적으로 느낀 쉼 3종. 점수·보상·꾸미기 성장과 연결하지 않는다.
- **기록 안내와 삭제:** 기분·메모·쉼 기록만 삭제할 수 있고 삭제 전 확인한다. 삭제해도 꾸미기·씨앗은 유지하며, 이미 받은 당일 보상이 다시 생기지 않는다.

첫 시작에 씨앗 12개를 제공한다. 연속 출석·미접속 벌점·경쟁 순위·유료 구매·확률형 보상은 없다. 게임은 정신건강 진단이나 치료를 제공하지 않는다. 워치의 심박수로 감정이나 정신건강 상태를 추정하지 않는다.

## 저장과 네트워크

게임 화면은 앱에 포함된 HTML/CSS/JavaScript를 Android WebView에서 표시한다. 외부 URL과 네트워크 요청은 WebViewClient 및 CSP에서 차단한다. 새 권한을 추가하지 않았다.

기록은 Android `getNoBackupFilesDir()`의 `mind-island-v1.json`에 `AtomicFile`로 저장한다. 마음섬은 기록을 서버에 보내거나 자동 공유하지 않으며 클라우드 백업에 포함하지 않는다. 마지막 180개의 날짜를 보관하고 화면에는 최근 일주일의 마음 기록을 보여준다. 앱을 제거하면 이 기록도 제거된다. 읽기에 실패하면 기존 파일을 덮어쓰지 않고 저장을 중단한다. 쓰기 실패 시 화면 상태를 확정하지 않는다.

이 설명은 새 **마음섬 모듈**에 해당한다. 원 제조사 앱과 타사 SDK의 네트워크 기능을 제거한 것은 아니다. 원 앱의 온라인 강제 업데이트 안내도 별개의 미해결 항목이다.

## 워치 데이터

현재 퀘스트는 **자가 기록 방식**이다. 실제 걸음 수·수면·심박수 연동이 구현되었다고 표시하지 않는다. 워치가 없어도 게임의 모든 기능을 사용할 수 있다. 건강 데이터 연결은 실물 Diz-SW01의 연결 경로를 검증한 뒤 별도로 구현한다.

## 소스와 빌드

- `features/mind-island/src/`: 네이티브 Activity, 저장 계층, WebView 제한.
- `patches/base/assets/mind-island/`: 화면·게임·데이터 모델.
- `patches/base/res/layout/v2_status_item_step.xml`: 건강 홈 진입 카드.
- `patches/base/smali_classes19/com/sma/smartv3/ui/main/MainActivity.smali`: 진입 메서드.
- `scripts/Compile-MindIsland.ps1`: Java → DEX 20 컴파일. 생성된 `patches/base/classes20.dex`는 Git에서 제외하며 빌드 시 재생성한다.
- `tests/mind-island-model.test.cjs`: 보상·날짜·꾸미기·삭제·정규화 테스트.

Java 17 이상(이 PC는 Android Studio JBR 25 사용), Python, Android SDK platform 35와 build-tools 35.0.0이 필요하다.

```powershell
$env:ANDROID_HOME = 'C:\Android\Sdk'
$env:SMART_TIME_WORKSPACE = 'C:\build\diz-ui' # 작업 공간이 다른 위치에 있을 때만 지정
.\scripts\Build.ps1 -IdentityProfile .\profiles\diz-sw01-mind-island.json
node .\tests\mind-island-model.test.cjs
```

결과: `dist/Diz_SW01_Mind_Island_0.3.0_ARM64_TEST.apk`.

## 검증 기록

2026-11-03, API 31 Google APIs 에뮬레이터에서 다음을 확인했다.

- 데이터 모델 테스트 15개와 JavaScript 구문 검사 통과.
- Java Activity → DEX 20 컴파일, APK 재조립, 서명 v2·v3 및 ZIP 정렬 검사 통과.
- 실제 건강 홈 카드로 마음섬 진입, 4개 메뉴 전환, 섬·꾸미기·호흡·퀘스트 화면 확인.
- 기분과 메모 저장 후 씨앗 12 → 17 증가, 같은 날 다시 제출해도 17 유지.
- 꾸미기 2종 구입·자리 배치·무료 배경 선택 후 상태 파일에 정확하게 반영.
- 앱 강제 종료 후 재실행 시 기분·메모·꾸미기·씨앗·배경 복원.
- 호흡 게임 일시정지 상태가 5초 동안 동일하게 유지되는 것을 스크린샷으로 비교. 이어서 실제 누적 60초 완료 후 씨앗 3개 지급 확인.
- 산책 대신 앉아서 몸 풀기를 선택하고 퀘스트 완료, 중복 탭에도 보상 한 번만 지급 확인.
- 주관적 쉼 기록이 저장되며 씨앗 점수는 변하지 않는 것을 확인.
- 확인 후 테스트 기분·메모·쉼만 삭제되고 꾸미기·씨앗·보상 이력은 남는 것을 확인.

검사에는 개발자가 입력한 샘플 기록만 사용했다. 검사 후 마음섬의 시작 상태를 복원하고, 기존 앱의 계정·건강 데이터는 변경하지 않았다. 원 앱의 제조사 강제 업데이트 문제 때문에 현재 에뮬레이터는 오프라인 UI 미리보기 상태다. 게임은 그 상태에서 전 기능을 검증했다.
