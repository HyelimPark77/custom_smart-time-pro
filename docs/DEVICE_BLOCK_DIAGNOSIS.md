# Galaxy S25 실기기 설치 차단 진단 — 2026-11-02

사용자가 USB 디버깅을 허용한 뒤 읽기 전용 ADB 진단을 수행했고, 커스텀 APK를 다시 열어 경고를 재현했습니다. 앱 설치·삭제, 보안 설정 변경, 로그 삭제, 시스템 앱 수정은 수행하지 않았습니다. 일련번호·개인 로그·스크린샷은 공개 저장소에 추가하지 않았습니다.

## 실기기에서 확인한 환경

| 항목 | 읽은 값 |
| --- | --- |
| 기기 | SM-S931N (Galaxy S25) |
| Android | 16 / API 36 |
| One UI 시스템 속성 | ro.build.version.oneui = 80500 |
| ABI | arm64-v8a |
| 메모리 페이지 | 4096바이트, 즉 4KB |
| com.diz.sw01.custom | 설치되지 않음 |
| com.sma.smartv3.pro | 설치되지 않음 |
| 경고 화면의 실제 컴포넌트 | android/com.samsung.android.core.pm.install.UnknownSourceAppBlockActivity |

안전하게 요약한 진단값은 [device_install_diagnosis.json](../analysis/device_install_diagnosis.json)에 있습니다.

## 확인된 차단 지점

경고를 직접 띄운 것은 **삼성 시스템 프레임워크의 UnknownSourceAppBlockActivity**입니다. 이번 중단 지점은 삼성의 외부 앱 설치 보안 차단 경로입니다. 사진으로 추정하던 단계에서 실제 전면 Activity를 확인했습니다. 그 전에 다른 검사 엔진이 관여했는지까지 배제한 것은 아닙니다.

삼성의 [2026년 공식 안내](https://news.samsung.com/kr/삼성전자-갤럭시-보안-사전-차단으로-고도화악성)는 One UI 6.1 이상 기기의 피싱 앱 설치 차단과 보안정책 갱신을 설명합니다. [같은 경고에 대한 Samsung Members 운영 담당자 답변](https://r1.community.samsung.com/t5/서비스-기타/악성-앱으로-의심/td-p/25249060)도 외부 배포 앱의 검토 경로를 안내합니다. 이 설명과 관찰된 삼성 차단 UI는 부합하지만, 이 APK에 적용된 내부 판정 규칙은 확인하지 못했습니다.

## 이전 원인 후보의 재평가

- **16KB 네이티브 정렬:** 두 라이브러리의 미충족은 별도 호환성 과제입니다. 이번 기기는 실제 4KB 환경이고 앱 실행 전 설치 차단이 발생하므로 현재 증상을 이 문제로 설명하지 않습니다.
- **기존 설치본과의 서명 충돌:** 새 앱은 별도 앱 ID이고 검사 시 원본·커스텀 패키지 모두 설치돼 있지 않았습니다. 관찰된 경고도 일반적인 업데이트 서명 충돌 메시지가 아닙니다.
- **앱 내부 로그인·서버·런타임 무결성 검사:** 앱이 설치·실행되지 않은 단계이므로 현재 중단을 앱 실행 후의 서버 거부로 설명할 수 없습니다.
- **서명·정렬·split·ABI:** [정적 검사](INSTALLATION_AUDIT.md)는 통과했지만 보안 판정 승인이나 안전성 검증을 뜻하지 않습니다.

## 아직 알 수 없는 부분

경고를 재현하며 설치·보안 태그와 최근 로그를 확인했으나 내부 분류 코드, 규칙명, 특정 SDK·권한을 지목하는 판정 사유는 확보하지 못했습니다. 삼성 ASKS 서비스는 존재했지만 기본 dumpsys에서 상세 사유가 출력되지 않았습니다. **특정 ASKS 규칙, 오탐 또는 실제 악성을 확정한 상태가 아닙니다.**

공개 Download 폴더에서 커스텀 파일명을 찾지 못해 휴대폰에 전달된 파일의 해시는 검증하지 못했습니다. 배포 산출물의 SHA-256은 Release 자료에 기록돼 있습니다. 배포 파일 검사와 휴대폰의 다운로드 파일 해시 검증을 구분합니다.

## 다음 해결 단계

1. 삼성 지원에 컴포넌트·모델·OS·페이지 크기·앱 ID·APK 해시·경고를 제공하고 **실제 판정 사유와 공식 재검토 절차**를 요청합니다. [삼성 공식 안내](https://www.samsungsvc.co.kr/solution/2683703?assess=N)의 Samsung Members 오류 보내기 절차를 참고하세요. 개인 계정·일련번호·건강 기록은 공개 이슈에 올리지 않습니다.
2. 필요한 워치 기능에 맞춰 권한·서비스·SDK를 검토하고, 불필요한 기능은 초기화·호출·메뉴까지 함께 정리합니다. 정상적인 알림 전달 용도가 있어도 전체 APK의 안전성을 확인한 것은 아닙니다.
3. 문제 동작이 확인되면 수정 후 공식 판정과 실제 설치·실행을 다시 검증합니다. 이름·키 변경이나 보안 검사 우회로 해결됐다고 처리하지 않습니다.

이번 진단은 **삼성 설치 보안 차단 지점을 확인하고 일부 원인 후보를 배제**한 결과입니다. 내부 분류 근거와 설치 가능 여부를 해결한 상태는 아닙니다. APK·로그를 삼성·Google·제3자 분석 서비스에 자동 제출하지 않았습니다.
