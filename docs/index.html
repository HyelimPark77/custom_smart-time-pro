워치가 없어도 사용할 수 있나요?

마음 기록·일기, 호흡, 직접 완료하는 퀘스트와 섬 꾸미기는 워치 없이 사용할 수 있습니다. 건강 기록·걸음 미션·워치 음성·쉼 알림에는 지원 워치 연결이 필요합니다.

플랫폼 로그인이 필요한가요? 기록이 자동 공유되나요?

이 다운로드 페이지를 이용하는 데 플랫폼 로그인은 필요하지 않습니다. 마음섬의 일기·게임 기록을 플랫폼 계정으로 자동 전송하거나 연결하는 기능은 제공하지 않습니다. 기존 건강 앱의 계정 및 건강 기록 처리와 마음섬의 기록은 구분됩니다.

설치가 차단되거나 업데이트가 안 돼요.

기존 앱과 다른 서명, 기기 환경, 설치 정책에 따라 업데이트가 안 될 수 있습니다. 기록 보존을 위해 기존 앱을 먼저 삭제하지 마세요. 보안 경고가 나타나면 임의로 무시하지 말고 팀 담당자에게 오류 화면과 버전을 알려 주세요.

현재 어떤 부분을 더 확인하고 있나요?

반복 음성 연결과 재연결, 재부팅·장시간 절전 후 예약 알림, 실제 걸음 미션과 수면 기록의 전체 흐름 등은 추가 검증 대상입니다. 건강 수치 변화에 따른 자동 알림과 꾸민 섬의 워치페이스 전송은 포함되어 있지 않습니다.
